Función: int()

Convierte un valor a un número entero.

entero = int("101")
print(entero) # 101

# Trunca los decimales, no redondea
print(int(9.8)) # 9
2 / 8

Función: float()

Convierte un valor a un número de punto flotante.

precio_str = "19.99"
precio_float = float(precio_str)

print(precio_float) # 19.99
3 / 8

Función: str()

Convierte cualquier objeto a su representación en texto.

numero = 42
texto = str(numero)

print("El número es: " + texto)
4 / 8

Función: bool()

Convierte un valor a Verdadero o Falso.

# 0, "" o [] son Falsos
print(bool(0)) # False

# Cualquier otra cosa es Verdadera
print(bool("Hola")) # True
5 / 8

Función: list()

Convierte una secuencia (tupla, string, etc.) en una lista.

palabra = "Python"
lista_letras = list(palabra)

print(lista_letras) # ['P', 'y', 't', 'h', 'o', 'n']
6 / 8

Función: tuple()

Convierte un iterable (como una lista) en una tupla.

numeros = [1, 2, 3]
tupla_numeros = tuple(numeros)

print(tupla_numeros) # (1, 2, 3)
7 / 8

Función: set()

Convierte un iterable en un conjunto (elimina duplicados).

lista = [1, 2, 2, 3, 1]
conjunto = set(lista)

print(conjunto) # {1, 2, 3}
8 / 8
